# Gate-Sense & Key-Attunement

> **Source:** BESM 4e Chapter 14, pp. 309–311 (Cosmic Web / Keys) + Ch.3 templates.

## The Powers

- **Key-attunement** — a soul's bond to a specific gate; can lock/open it, detect it.
- **Gate-sense** — read the waylines, the doors, the Chamber's resonance (the gatekeepers' hallmark).
- **Skeleton Key bond** — the rare power to operate any gate, destroy gates, pick any lock.
- **Way-Bound** — souls linked to the Cosmic Web, summonable by true-name ritual.

## Powers → card_json

Key-attunement, Gate-sense, Skeleton Key bond, Way-Bound all have **no DB column** — they live in `card_json.powers` + the `race` column as narrative, injected as prose (the established six-Prime pattern). The loadout DB columns carry techniques/skills/defects + Narrative Syntax.
